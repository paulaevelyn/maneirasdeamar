# Maneiras de amar

Recursos interativos de psicoeducação da **Psicoterapia e Afins**, plataforma de
saúde mental da psicóloga clínica Paula Rodrigues (CRP ativo, atendimento online
para adultos no Brasil e na Europa).

Cada recurso é um arquivo HTML único e autocontido, publicado via GitHub Pages e
embedado por iframe no site em WordPress.

## Princípios

- **Nada sai do navegador.** As respostas ficam em `localStorage`, no dispositivo
  de quem usa. Não há coleta, envio ou armazenamento externo de dados.
- **Honestidade científica.** O conteúdo é traduzido da literatura da área para
  linguagem cotidiana, e cada recurso credita suas referências.
- **Não é diagnóstico.** Os materiais são psicoeducativos e de autoconhecimento.
  Não substituem avaliação psicológica nem acompanhamento clínico.
- **Sem dependências.** HTML, CSS e JavaScript puros, sem frameworks e sem
  bibliotecas externas, com exceção do Google Fonts.

## Recursos

| Arquivo | Tema |
|---|---|
| `apego.html` | Teoria do apego: os quatro estilos de apego adulto, questionário de autorreflexão nas dimensões de ansiedade e evitação, e plano prático de segurança conquistada. |

## Publicação

Os arquivos ficam na raiz do repositório e são servidos pelo GitHub Pages, por
exemplo `https://paulaevelyn.github.io/maneirasdeamar/apego.html`.
